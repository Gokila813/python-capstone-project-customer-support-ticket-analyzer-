# Customer Support Ticket Analyzer 🎫📊

A Python-based capstone project built as part of my Data Analysis course. This project stores, cleans, and analyzes customer support ticket data to help identify common issues, customer sentiment, and areas for service improvement.

## 📌 Problem Statement

Customer support teams handle numerous service tickets daily. Analysing these tickets helps identify common issues, customer sentiment, support quality, and areas for improvement. This project builds a Python-based Ticket Analysis System that stores, cleans, analyses, and extracts insights from customer support tickets.

## 🚀 Features

- **Preloaded Ticket Data** — Stores ticket records (Ticket No, Customer Name, Issue Description, Priority) using a dictionary-based structure
- **Formatted Table Output** — Displays ticket data in a clean, readable tabular format
- **Dynamic Ticket Entry** — Allows new tickets to be added interactively via user input
- **Text Cleaning** — Cleans and standardizes issue descriptions (removes punctuation, normalizes case, fixes common typos) for accurate analysis
- **Keyword Extraction & Insights** *(in progress)* — Extracts key terms and summary statistics from ticket data

## 🛠️ Tech Stack

- Python 3
- Google Colab
- Core concepts: Dictionaries, Lists, String Manipulation, Loops, Sets
